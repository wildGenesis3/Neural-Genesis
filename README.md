# Neural Genesis — Foundational AI Architecture for the Enterprise

> Purpose-built products and practical AI architecture for modern enterprise workflows.

Neural Genesis delivers a unified enterprise foundation powering intelligent automation across workforce operations, supply chain logistics, generative media, and real-time commerce.

---

## 🌟 Core Products

- **HRDeeds** — Autonomous HR & workforce intelligence, shift scheduling, real-time payroll forecasting, and talent flight risk prediction.
- **RoutePulse** — Predictive fleet routing, multi-stop optimization, dynamic dispatch rerouting, and fuel burn telemetry.
- **Stories** — Generative brand narrative studio, AI copy synthesis, and multi-channel asset distribution.
- **LinaKart** — Intelligent commerce & dynamic merchandising, real-time cart personalization, and predictive re-order triggers.

---

## 🚀 Upcoming Pipeline (Roadmap)

- **Operational CCTV** — Real-time neural computer vision for workplace safety, hazard detection, and operational oversight.

---

## 🛠 Tech Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom Design System with responsive mobile/tablet breakpoints), Vanilla JavaScript (ES6+).
- **Backend**: Node.js & Express server with Gmail SMTP form delivery via Nodemailer.
- **Design System**: Tailored HSL color palette, Space Grotesk & Geist typography, glassmorphism, responsive data visualizations.

## 🏁 Quickstart

1. **Clone the repository:**
   ```bash
   git clone https://github.com/wildGenesis3/Neural-Genesis.git
   cd Neural-Genesis
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment:**
   ```bash
   cp .env.example .env
   # Edit .env with your Gmail SMTP credentials
   ```

4. **Start the local server:**
   ```bash
   npm start
   # Application runs at http://localhost:3000
   ```
