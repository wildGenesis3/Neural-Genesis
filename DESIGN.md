## Brand & Style

The visual narrative bridges the rigor of an advanced enterprise AI laboratory with the luminous clarity of modern engineering platforms. It communicates technical authority, precision, and ambient intelligence without resorting to chaotic dark-mode sci-fi clichés.

The target audience encompasses enterprise technology leaders, product builders, engineers, and innovation executives seeking foundational AI architecture. The emotional signature is calm confidence, meticulous precision, and intellectual clarity.

The aesthetic fuses **Minimalism** with an **Experimental Technical Laboratory** posture:
- Crisp white and surgical off-white canvas foundations.
- Mathematical grid structures paired with high-impact cyan and deep navy contrasts.
- Razor-sharp typographic tension: structural, expressive geometric headlines set against developer-grade, neutral sans-serif body copy.
- Restrained, architectural surface treatments prioritizing structural borders, clean dividers, and focused light dynamics over decorative ornament.

## Colors

The palette establishes an ultra-clean optical balance between deep oceanic structural tones and radiant, high-energy computational accents.

### Core Roles
- **Primary (`#10BDF4` - Electric Cyan):** The core kinetic signal. Used for interactive focus rings, active indicator pings, terminal highlights, and energetic data visualizations.
- **Secondary (`#0878F5` - Action Blue):** The primary interactive driver. Powers primary call-to-action buttons, high-priority links, and focused selection states where robust WCAG AA contrast against white is mandatory.
- **Tertiary (`#062D63` - Deep Signal Navy):** The authoritative anchor. Governs all primary headings, heavy structural iconography, and key structural framing.
- **Neutral (`#475569` - Slate Neutrals):** The descriptive layer. Standardizes secondary content, metadata, and long-form narrative body copy.

### Canvas & Surface Hierarchy
- **Base Canvas (`#FAFAFC`):** Soft, anti-glare clinical white for the root document.
- **Surface Elevation 0 (`#FFFFFF`):** High-purity white used for modular cards, interactive input panels, and raised data containers.
- **Surface Elevation 1 (`#F1F5F9`):** Subdued technical panel fills, table headers, and inactive badge backgrounds.
- **Structural Lines (`#E2E8F0`):** Hairline precision borders providing distinct modular separation.

### Product Vector Accents
Subtle contextual accents identify distinct modular AI offerings within the suite:
- **HRDeeds:** Accent Blue (`#0878F5`)
- **RoutePulse:** Cyan Teal (`#0D9488`)
- **Stories:** Ambient Amber (`#F59E0B`)
- **LinaKart:** Emerald Growth (`#10B981`)

## Typography

Typography delivers a calculated dialogue between human vision and computational execution:
- **Headlines (Space Grotesk):** Engineered geometric grotesque. Its proportional idiosyncrasies, alternate ink-traps, and tight tracking project the forward-looking intensity of an AI research lab.
- **Body & Interface (Geist):** Developer-grade neutral sans-serif. Delivers maximum clarity at low point sizes and high information densities.

### Implementation Rules
- Headings set in Space Grotesk require negative letter-spacing to maintain cohesion across viewport scales.
- Never use Space Grotesk for body copy or descriptive metadata exceeding 40 characters.
- All interface controls, technical metrics, table cells, and status indicators strictly use Geist medium or semibold weights.
- All capitalized micro-labels (`label-sm`) require `letterSpacing: 0.06em` and `text-transform: uppercase` for instantaneous visual triage.

## Layout & Spacing

The layout model is anchored by an uncompromising 12-column responsive fluid grid structured around 8px baseline rhythm intervals.

### Grid & Breakpoints
- **Desktop (>= 1200px):** 12-column layout, `margin-lg` (80px) outer edge margin, `gutter-lg` (32px) columns, max content container width of 1280px.
- **Tablet (768px - 1199px):** 8-column layout, `margin-md` (48px) margin, `gutter` (24px) columns.
- **Mobile (< 768px):** 4-column layout, `margin` (24px) margin, `gutter-sm` (16px) columns.

### Spatial Rhythm
- **Micro Spacing (`space-xs` to `space-sm`):** Internal component relationships (icon-to-text, chip padding, badge metrics).
- **Core Component Spacing (`space-md` to `space-lg`):** Standard input heights, card interiors, and vertical form grouping.
- **Structural Layout Spacing (`space-xl` to `space-3xl`):** Card-to-card gaps, grid module rows, and primary section breaks. Section headers use `space-xl` bottom separation to prevent decoupling from associated grid content.

## Elevation & Depth

Visual hierarchy rejects heavy, opaque shadows in favor of low-contrast hairline outlines coupled with high-diffuse, cold-tinted ambient atmosphere.

### Depth Archetypes
1. **Flat Structural Base (Elevation 0):**
   - Background: `#FFFFFF` on `#FAFAFC`.
   - Border: 1px solid `#E2E8F0`.
   - Shadow: None. Used for baseline dashboard surfaces and structural content cards.

2. **Ambient Hover & Floating Panels (Elevation 1):**
   - Background: `#FFFFFF`.
   - Border: 1px solid `#CBD5E1`.
   - Shadow: `0 4px 20px -2px rgba(6, 45, 99, 0.04), 0 2px 6px -1px rgba(6, 45, 99, 0.02)`.
   - Application: Product preview cards, dropdown menus, and interactive card hovers.

3. **Overlay & Focal Modals (Elevation 2):**
   - Background: `#FFFFFF`.
   - Border: 1px solid rgba(16, 189, 244, 0.25).
   - Shadow: `0 20px 40px -8px rgba(6, 45, 99, 0.08), 0 1px 3px 0 rgba(6, 45, 99, 0.04)`.
   - Application: System dialogs, command palettes, and active flyouts.

4. **Electric Glow (Active Signal):**
   - Border: 1px solid `#10BDF4`.
   - Shadow: `0 0 0 3px rgba(16, 189, 244, 0.15)`.
   - Application: Focused input states, active radio toggles, and processing state triggers.

## Shapes

The design system enforces a **Soft Geometric** baseline (`roundedness: 1`), conveying structural integrity and industrial refinement.

### Corner Radii Tokens
- **Base Elements (`rounded` = 0.25rem / 4px):** Checkboxes, inline code tags, breadcrumb segments, and micro badges.
- **Interactive Controls (`rounded-md` = 0.375rem / 6px):** Form fields, standard buttons, tabs, and filter pills.
- **Containers & Modules (`rounded-lg` = 0.5rem / 8px):** Dropdown menus, modal dialogs, and nested preview containers.
- **Structural Master Panels (`rounded-xl` = 0.75rem / 12px):** Primary portfolio cards and hero product showcases.

Large sweep corners (e.g., full pill shapes or oversized 24px+ curves) are explicitly banned for structural containers to preserve crisp architectural lines.

## Components

### Buttons
- **Primary:** Background `#0878F5`, text `#FFFFFF`, border none, `rounded-md` (6px), Geist Medium 14px. Hover: `#0663CC`. Focus: Ring 3px rgba(16, 189, 244, 0.4).
- **Secondary / Outline:** Background `#FFFFFF`, text `#062D63`, border 1px solid `#E2E8F0`. Hover: Border `#CBD5E1`, background `#F8FAFC`.
- **Ghost:** Background transparent, text `#475569`. Hover: Text `#062D63`, background `#F1F5F9`.

### Chips & Badges
- Height 24px, padding 0 8px, `rounded` (4px).
- Font: Geist Semibold 11px uppercase (`label-sm`).
- Neutral variant: Background `#F1F5F9`, border 1px solid `#E2E8F0`, text `#475569`.
- Dynamic Accent variant (e.g., active telemetry): Background rgba(16, 189, 244, 0.08), border 1px solid rgba(16, 189, 244, 0.3), text `#062D63`. Includes a 6px pulsing dot in `#10BDF4`.

### Input Fields
- Height 40px, padding `0 12px`, background `#FFFFFF`, border 1px solid `#CBD5E1`, `rounded-md` (6px).
- Typography: Geist Regular 14px, placeholder `#94A3B8`.
- Focus state: Border `#10BDF4`, box-shadow `0 0 0 3px rgba(16, 189, 244, 0.15)`.

### Checkboxes & Radios
- Size: 16px x 16px, border 1px solid `#CBD5E1`, `rounded` (3px) for checkboxes, circular for radios.
- Checked: Background `#0878F5`, border `#0878F5`, white checkmark or inner dot.

### Cards & Modular Showcase Containers
- Background `#FFFFFF`, border 1px solid `#E2E8F0`, radius `rounded-xl` (12px), padding `space-lg` (24px).
- Hover transition: 200ms ease-out, border color becomes `#CBD5E1`, elevation rises to Elevation 1.
- Top-edge subtle product accent: An optional 2px inset hairline line across the upper border signaling product taxonomy (Blue for HRDeeds, Teal for RoutePulse, Amber for Stories, Emerald for LinaKart).

### Technical Telemetry & Code Previews
- Terminal shells and preview viewports use `#0F172A` (Slate 900) interiors embedded cleanly inside `#FFFFFF` cards, framed with a 1px `#E2E8F0` border and 8px interior radius, utilizing Geist Monospace for telemetry readouts.
